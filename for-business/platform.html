The Experience Delivery Stack

Six tools, one stack.

The stack is built for L&D leaders running training that has to land, not for IT to babysit. Every tool slots together so cohorts move from baseline to credential without friction.

Manage learning groups

Organise learners by team, persona, region or grade. Assign content, run cohort campaigns and track progress from a single console.

  • Bulk user import via CSV or SCIM
  • Cohort campaigns with reminders
  • Persona‑tagged learner directory

Skill assessments

Score every learner against the capability axes that matter to the role. Real‑time data, no guesswork, calibration you can defend in a leadership review.

  • Persona‑led benchmarking
  • Pre‑ and post‑program assessments
  • Strengths and gap diagnostics

Semesterised learning

Structured blocks instead of an infinite buffet. Each semester has a goal, a deadline and a credential, so learners know exactly what they are working toward.

  • Fixed‑term blocks with deadlines
  • Milestone‑driven completion
  • Calendar‑native scheduling

Custom path builder

Drag and drop courses, assessments and projects into a path tailored to the role. Save it as a template, clone it for the next cohort, version it as the role changes.

  • Drag‑and‑drop sequencing
  • Reusable role templates
  • Versioning and rollback

Blended programs

Track instructor‑led sessions, virtual workshops, projects and self‑paced lessons inside one program. Attendance, completion and skill gain in one report, every time.

  • ILT, VILT and self‑paced in one view
  • Attendance and engagement tracking
  • Project submissions and reviews

Reporting & analytics

The dashboards your CFO will actually open. Engagement, completion, skill gain and ROI proxies, broken down by persona, cohort and region.

  • Cohort, persona and individual dashboards
  • Reporting API for BI exports
  • Scheduled email digests
Learner Experience

Designed to keep
working professionals shipping.

Bite‑sized lessons, hands‑on projects and credentialed assessments. Built for the analyst who can spare five minutes between deliverables, not a four‑hour university lecture.

  • 5‑minute lessons, 50‑minute courses

    Each course is a single CPE credit, about fifty minutes, broken into focused five‑minute lessons. Built around the cadence of consulting and finance work, not a 90‑minute university lecture.

  • Practice files for every lesson

    Excel workbooks, Power BI files, Python notebooks and SQL datasets, downloadable in one click and tied to the lesson scenario.

  • Project‑based learning

    Apply the skills inside scenarios drawn from real client engagements: dashboard audits, valuation models, risk reviews, board packs.

  • CPD, CPE and NASBA accredited

    Every credential learners earn counts toward continuing professional development credits and lands shareable on LinkedIn the moment it is awarded.
