An Updated Kubicle Experience, Launching January 26th

Kubicle News 19 Jan 2025 3 min read

A Clearer, More Modern Experience

As Kubicle has grown, so has the depth of what teams can do on the platform. One of the main goals of this update was to make that experience clearer and easier to navigate.

The updated UI introduces a cleaner layout, improved structure and clearer separation between different types of content. For admins, this makes it easier to set up programs, assign learning and review progress. For learners, it creates a more focused experience where expectations and progress are easy to understand.

The aim is simple: reduce friction and help everyone spend more time on learning itself.

Better Tools for Managing Learning Groups

This update also introduces improvements to how learning groups are managed and supported.

Admins now have access to an expanded Learning Group Management Suite, designed to make it easier to monitor engagement and support learners throughout a program. This includes leaderboards that highlight progress within groups, improved learner check-ins that support regular touchpoints, and clearer analytics that provide better visibility into how groups are performing.

Together, these tools help admins stay closer to learner progress and take action where support is needed.

A Faster Way to Set Up Learning Programs

We have also made it easier for teams to get started with structured learning.

The Semester Library provides access to expert-designed learning paths that can be launched quickly. Admins can also save their own semester configurations as templates and reuse them across their organization. This helps teams move faster while keeping programs consistent across groups and regions.

It is about giving teams confidence in both speed and structure.

More Accurate Skill Insight and More Relevant Learning

Skill Checks have also been updated as part of this release.

Previously, Skill Checks relied on learners assessing their own skill levels. While this approach was simple, it often made it difficult to get a clear picture of current capability.

With the updated Skill Checks, learners now complete short, performance-based quizzes. Skill levels are determined by how learners perform, rather than how they perceive their ability.

For organizations, this provides a more accurate and reliable view of skill levels across teams. For learners, it means learning time is focused on what matters most, reducing the need to work through content they already know.

Creating Space for New Ways to Learn

This update also creates space for Kubicle to expand how learning is delivered.

The redesigned UI allows Kubicle to deliver learning content in additional formats beyond videos and exams. This includes immersive projects that place learners in realistic environments using real screens, tools and task flows.

As we move forward, we will continue to introduce new formats that add variety, support different learning styles and allow learning to better match the subject matter.

What Happens Next

We are looking forward to sharing more when the update goes live on January 26. This release represents an important step forward in making Kubicle clearer, more practical and more flexible for teams delivering learning at scale.

More information, including a full walkthrough of the updated experience, will be shared at launch.
